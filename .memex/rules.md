# TenderWise AI Agent Rules

## Purpose
This document defines the rules and guidelines for the AI agent assisting with the TenderWise AI platform development project.

## Reference Repositories
The TenderWise AI platform draws inspiration and architectural patterns from the following repositories:
1. **[Langflow](https://github.com/langflow-ai/langflow)** - For workflow design and AI agent orchestration capabilities
2. **[FastAPI Full-Stack Template](https://github.com/fastapi/full-stack-fastapi-template)** - For backend architecture and API design
3. **[Xpander.ai](https://github.com/patchy631/xpander.ai)** - For AI integration patterns
4. **[Awesome LLM Apps](https://github.com/Shubhamsaboo/awesome-llm-apps)** - For LLM application best practices
5. **[AI Engineering Hub](https://github.com/patchy631/ai-engineering-hub)** - For AI engineering patterns and practices
6. **[Open WebUI](https://github.com/open-webui/open-webui)** - For modern UI/UX design and LLM integration

## General Rules

1. **Project Context Awareness**
   - Maintain awareness of the TenderWise AI platform's purpose, features, and technical specifications
   - Reference relevant project documentation when providing assistance
   - Consider the current project phase when offering recommendations

2. **Documentation Standards**
   - Follow the established documentation format and structure
   - Use Markdown for all documentation files
   - Include appropriate headers, lists, and code blocks for clarity

3. **Code Standards**
   - Follow the established coding standards for each language/framework:
     - Python: PEP 8 standards
     - JavaScript/TypeScript: Standard JS or project-specific linting rules
     - SQL: Consistent formatting with proper indentation
   - Include appropriate comments and documentation strings
   - Prioritize code readability and maintainability

4. **Technical Guidance**
   - Provide solutions aligned with the project's technical architecture
   - Consider performance, security, and scalability in all recommendations
   - Suggest best practices relevant to the technologies in use

5. **Project Management**
   - Respect the waterfall development methodology outlined in the project plan
   - Reference appropriate task IDs from the project breakdown when discussing work items
   - Consider dependencies between tasks when suggesting implementation approaches

6. **Security and Compliance**
   - Prioritize security best practices in all code and configuration recommendations
   - Ensure recommendations maintain data privacy standards
   - Flag potential security concerns when identified

7. **Communication**
   - Provide clear, concise explanations
   - Use visual aids (diagrams, tables) when helpful
   - Break down complex concepts into manageable components

## Technology-Specific Guidelines

### AI/ML Components
- Prioritize approaches that balance accuracy with performance
- Consider ethical implications of AI implementations
- Suggest appropriate validation metrics and testing approaches

### Database Design
- Follow normalized database design principles
- Include appropriate indexes and constraints
- Consider query performance optimization

### Frontend Development
- Ensure responsive design principles are followed
- Prioritize accessibility standards
- Maintain consistent UI/UX patterns

### API Development
- Follow RESTful or GraphQL best practices as appropriate
- Include proper error handling and status codes
- Document all endpoints thoroughly

## Project Phases Reference

The agent should be aware of the current project phase and adjust recommendations accordingly:

1. Environment Setup (Weeks 1-2)
2. Backend Development (Weeks 3-8)
3. Frontend Development (Weeks 5-10)
4. AI/ML Development (Weeks 7-12)
5. Integration (Weeks 13-14)
6. Testing (Weeks 15-16)
7. Deployment and Launch (Weeks 17-18)
